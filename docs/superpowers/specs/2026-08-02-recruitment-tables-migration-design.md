# 招生表格迁移设计

## 目标

在保留 GitHub 远程 `master` 最新站点及其完整历史的前提下，将本地快照中的招生信息迁移到首页。

## 范围

- 修改 `pages/home.html`，将现有单一招生说明拆成“博士招生”和“硕士招生”两个独立区块。
- 保留远程版本已有的博士招生要求。
- 增加本地快照中的硕士招生要求。
- 修改 `assets/css/site.css`，为两个招生区块增加标题和间距样式。
- 不迁移本地独立历史中的其他文件或旧版页面内容。

## 实现方式

以 `origin/master` 为基线，在 `codex/migrate-recruitment-tables` 分支手动应用两处局部变更。避免合并无共同祖先的历史，也不使用强制推送。

## 验证

- 检查 Git diff，确认只包含设计说明、首页招聘区和相关 CSS。
- 运行仓库现有的站点构建或验证命令。
- 检查生成页面中博士、硕士两个标题及各自条目均存在。
- 推送迁移分支并创建草稿 PR，由 GitHub 的分支保护和检查继续验证。

## 失败处理

若远程页面结构或构建工具发生变化，停止迁移并保留远程内容；只调整局部补丁，不回退或覆盖远程提交。
